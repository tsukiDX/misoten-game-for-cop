# Unity Local Multiplayer Cleaning Action Game

Unityで開発中の、最大4人対応ローカルマルチプレイ・アクションゲームです。

プレイヤーはジャイロ操作対応コントローラーを使い、掃除用具をモチーフにした武器で敵と戦います。

## ゲーム概要

各プレイヤーは個別のコントローラー、ジャイロポインター、HP、スキルゲージ、武器を持ちます。

武器によって、コントローラーの持ち方、ジャイロ操作、チャージ方法、攻撃判定が変化します。

### Bucket

コントローラーを横向きに持って使用します。

下向きに傾けて水を溜め、Rトリガーを押しながら下から上へ振ることで、水の波を前方へ飛ばします。チャージ量に応じて攻撃範囲が変化します。

### Mop

Rトリガーを上にした縦持ちで使用します。

Rトリガーを押している間、ジャイロポインターが敵へ触れるたびにダメージを与えます。

### Spray

Rトリガーを上にした縦持ちで使用します。

Rトリガーを押しながらコントローラーを縦に振ってチャージし、トリガーを離すとチャージ量に応じた攻撃を行います。

### Vacuum

コントローラーを横向きに持って使用します。

Rトリガーで敵をロックし、対象の周囲に表示される円形範囲内でポインターを動かします。蓄積した移動量に応じて、吸引強度と継続ダメージが上昇します。
